# Recherche 1602: Waren, Ketten, Inseln, Rohstoffe (Stand 30.10.2026)

Quelle: nur Suchtreffer-Ausschnitte. Alles **unsicher**, bis gegen annoinfo.de / Tim Howgego / anno-capsu geprüft.

## Ketten (soweit belegt)
- Holzfäller → Holz (erst ins lokale Lager, Marktkarren holt ab)
- Steinbruch + Steinmetz → Ziegel (1 Steinbruch reicht für bis zu 6 Steinmetze; Steinmetz braucht Wegeanschluss)
- Erzmine (Berg) → Erz → Erzschmelze (+ Holz) → Eisen → Werkzeugmacher → Werkzeug. Normale Erzmine erschöpft sich → tiefe Erzmine (ab 250 Kaufleuten). Köhler in 1602 unsicher.
- Goldmine (Berg) → Gold → Goldschmied (ab 200 Kaufleuten) → Schmuck. Gold erschöpft sich nicht.
- Fischerei → Nahrung (billigste Quelle); Getreidefarm → Mühle → Mehl → Bäckerei → Nahrung
- Weinreben → Kelterei → Alkohol; Zuckerrohr → Rumbrennerei → Alkohol (ab ~75 Pionieren bzw. 40 Siedlern)
- Tabakplantage → Tabakwarenmanufaktur → Tabakwaren; Gewürzplantage → Gewürze; Kakaoplantage → Kakao
- Schaf-Farm/Baumwolle → Weberei → Stoffe → Schneiderei → Kleidung (für 1602 nicht sicher belegt)
- Waffen: Kanonengießerei (ab 250 Kaufleuten); Schwerter/Musketen unsicher
- Werkzeug anfangs beim Händler kaufen

## Inseln
- Jede Insel ist für bestimmte Pflanzen fruchtbar (Anzeige in %), Getreide/Holz/Wolle überall.
- Norden: Tabak, Wein, Zuckerrohr. Süden: Kakao, Baumwolle, Gewürze.
- Erz und Gold nur auf Bergen; kleine Inseln oft fruchtbarer und mit Erz/Gold.
- Wüste/Steppe weniger fruchtbar als grüne Flächen. Ureinwohner auf manchen Inseln.

## Bedarf (GameStar 1998)
Siedler: Stoffe, Kapelle · Bürger: Tabakwaren, Alkohol, Gewürze, Wirtshaus · Kaufleute: Kakao, Kleidung, Badehaus, Kirche, Schule · Aristokraten: Schmuck, Hochschule, Theater.
Steam-Guide: Bürger dürfen eins von vier Gütern (Stoffe, Alkohol, Tabakwaren, Gewürze) fehlen lassen.
